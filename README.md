# 🚀 SOLOLEARN - Spring Boot MVC Project

A **full-stack e-learning web application** built using **Spring Boot MVC** that enables students to learn programming languages through structured courses, blogs, and interactive content. The platform provides secure authentication, user profile management, and an admin dashboard to manage educational resources.

---

## 📖 Project Overview

SOLOLEARN is a self-learning platform where users can register, log in, and learn various programming languages at their own pace. The application follows the **MVC architecture** and provides role-based access for Students and Admins.

Students can access learning materials, read blogs, update their profiles, and explore programming content, while the Admin can manage users, posts, and learning resources through a dedicated dashboard.

# 🏗️ Project Architecture

The application follows the **Spring Boot MVC Architecture**.

```
Controller
     │
     ▼
Service Layer
     │
     ▼
Repository Layer
     │
     ▼
MySQL Database
```

This layered architecture improves maintainability, scalability, and code organization.

# 🎯 Purpose of the Project

The main objective of this project is to provide an online platform where students can:

- Learn programming languages independently
- Access educational blogs and tutorials
- Improve coding knowledge
- Maintain their learning profile
- Experience a simple and user-friendly interface

The project also demonstrates the implementation of a real-world **Spring Boot MVC application** with authentication, CRUD operations, role-based access, and database integration.
